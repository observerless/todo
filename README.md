어른(Adult)을 그리실 때는 24x24 캔버스를 넓게 꽉 채워서 그리시면 됩니다.

💡 도트 수정 기본 원리
이 캐릭터들은 가로 24, 세로 24 사이즈의 모눈종이(viewBox="0 0 24 24") 위에 그려져 있습니다.
코드 안의 <rect x="7" y="10" width="10" height="10" /> 같은 코드가 바로 픽셀 네모 하나하나를 의미합니다.

x: 오른쪽으로 얼만큼 이동할지 (0~24)

y: 아래쪽으로 얼만큼 이동할지 (0~24)

width, height: 네모의 가로, 세로 길이

🛠️ 수정 방법 예시 및 위치
1) 몸통 모양 바꾸기
renderCharacter 함수 안에 보시면 아래처럼 단계와 타입별로 코드가 나뉘어 있습니다.

JavaScript
if (stage === 'egg') {
    // 알 모양 도트 코드
    bodySvg = <g><rect x="7" y="10" width="10" height="10" /> ... </g>;
}
// ...중략...
else if (charType === 'smart') {
    if (stage === 'child') bodySvg = <g> ... </g>;
}
여기서 <rect> 값들의 좌표와 크기를 바꾸거나, 새로운 <rect> 태그를 추가/삭제해서 모양을 깎고 다듬을 수 있습니다.

2) 표정 바꾸기
const drawFace 함수를 찾으시면 됩니다.

JavaScript
const drawFace = (x, y, face, bg) => {
    if (face === 'happy') return <g ...> 눈웃음 좌표 </g>;
    if (face === 'sad') return <g ...> 우는 눈 좌표 </g>;
    // ...
}
눈과 입을 그리는 위치가 지정되어 있습니다. (x, y 값을 바꿔서 눈 사이 간격을 벌리거나 입 모양을 바꿀 수 있습니다.)

3) 착용 아이템 모양 바꾸기
renderCharacter 함수 맨 밑에 보면 아이템을 그려주는 부분이 있습니다.

JavaScript
if(item.id === 'i_glasses') return <g><rect x="7" y="9" .../></g>;
안경이나 왕관 등의 크기, 위치를 변경하고 싶다면 이 부분을 조작하면 됩니다.

⚠️ 도트 수정 시 주의할 점 (색상 연동)
코드를 보면 색상을 #000000처럼 직접 지정하지 않고 fill={px} (테두리/어두운색) 또는 fill={bg} (배경/밝은색) 변수를 사용하고 있습니다.

도트를 새로 찍으실 때도 무조건 색상 속성에 fill={px}나 fill={bg}를 넣어주셔야 새벽/오전/오후/밤 시간에 맞춰 캐릭터 색상이 자연스럽게 변합니다!
